3 - Función como Promesa

Función como promesa

Esta es una función que devuelve una promesa.

La promesa se resuelve si el número es par, y se rechaza si el número es impar.

La promesa se resuelve con el mensaje "¡¡Es par!!" si el número es par, y con el mensaje "Mal!!!" si el número es impar.

La promesa se rechaza con el mensaje "Error" si el número no es un número.
