Clase 27 - 01 - Advanced Validation - Técnicas para desarrollo de plugins complejos

Con valores por defecto

Sin opciones: al enviar, valida los campos con data-basic-validation-required.

El comentario lleva la clase .basic-validation pero no el data attribute, así que no se exige.

Con hooks

onInit al crear el plugin. onValidating, onIsValid, onIsNotValid y onValidated al validar.

Método isValid

El botón llama a validate y después a isValid.

Método option

Lee y cambia message. Enviar con un campo vacío muestra el texto vigente.

Validación avanzada (regex y longitud)

Campos con clase .advanced-validation y atributos data-advanced-validation-*: obligatorio, regex, mínimo y máximo. Mensaje bajo cada campo inválido.

Método destroy

Antes de destruir, un envío vacío se queda en la página. Después, el formulario se envía sin validar.
